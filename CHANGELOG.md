# Changelog

All notable changes are documented here. This project follows Semantic Versioning while recognizing that pre-1.0 releases may change APIs.

## 0.1.0 - 2026-08-28

### Added

- Installable DSH bundle registering `dsh-capsule`, `dsh-teach`, and `dsh-time-machine`.
- Safe capsule creation, verification, inspection, and controlled extraction.
- Evidence-backed Skill analysis and paired baseline/treatment evaluation.
- Controlled trajectory comparison with privacy-aware reports.
- Synthetic tests, a real-model evaluation example, CI, and release verification.

### Security

- Resource limits, ZIP path and symlink checks, manifest hash validation, structured secret redaction, Session identifier aliasing, and hidden-reasoning removal from public evaluation evidence.
